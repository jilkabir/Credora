# Credora profile

A profile should answer three questions quickly:
1. What does this person actually do?
2. Why should I believe them?
3. What should I do next?

## Inputs

Use the user's headline, about section, current and recent experience, featured
items, banner, skills, recommendations, and target audience when available.

## Score

Use `rubric.json`. Score conservatively. Do not award proof points for vague
claims.

## Rewrite order

1. headline
2. first two visible lines of about
3. about body
4. featured section
5. recent experience
6. banner guidance
7. skills/recommendations/contact gaps

## Credora upgrades

- Separate **verified proof** from unsupported positioning claims.
- Flag claims that need evidence.
- Match wording to the user's target audience.
- Avoid template headlines when they erase real expertise.
- Do not invent metrics to improve the score.
- When the user has multiple professional identities, prioritize the one aligned
  with their stated LinkedIn goal instead of stuffing every title into one line.

## Output

Score table, biggest credibility gaps, copy-ready rewrites, then a re-score.
