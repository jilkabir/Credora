# Credora performance-review

The user's own account data is more useful than generic growth rules, but small
samples are noisy.

## Inputs

Use any combination of:
- impressions
- reactions
- comments
- reposts
- saves/sends if available
- follower count at time of post
- format
- topic
- hook
- publish time
- leads or conversations generated

## Metrics

Calculate relevant rates only when denominators are available. Never pretend
missing metrics exist.

Examples:
- engagement rate
- comment-to-reaction ratio
- reach multiple
- save/send rate
- lead rate when the user tracks it

## Confidence

For every conclusion state:
- sample size
- observed difference
- plausible confounders
- confidence: low / medium / high

Do not turn 4 or 6 posts into a universal rule.

## Output

Top and bottom patterns, what is likely signal versus noise, what to test next,
and which planning assumptions should be updated.
