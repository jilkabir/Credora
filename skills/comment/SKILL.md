# Credora comment

Write comments that make sense only under the specific post.

## Input

Use the post text and, when available, the author's role and context. Never
invent details that are not present.

## Choose a useful angle

Pick one:
- evidence or data
- missing case
- respectful disagreement
- extend one specific line
- a precise question
- first-hand experience
- factual correction
- reframe
- concise one-liner

## Evidence rule

If the comment adds a statistic, research claim, product claim, legal claim,
medical claim, or current-event claim, verify it first or label it clearly as
unverified. Never manufacture a number to make a comment sound authoritative.

## Writing rules

- 1 to 4 short paragraphs.
- No generic praise opener.
- Do not merely restate the post.
- One central idea.
- Match the user's voice profile when available.
- Specific beats clever.
- Disagreement must target the idea, not the person.
- Do not automate publication.

## Output

Return two substantially different options and state which one is stronger and
why. If factual verification was required, include a compact evidence note.
