# Credora reply

Classify before writing.

## Buckets

- LEAD: describes a problem the user can genuinely help with
- SUBSTANCE: adds evidence, disagreement, nuance, or a useful question
- PEER: useful professional relationship or domain peer
- SUPPORT: praise, emoji, tag, short encouragement
- NOISE: spam, irrelevant pitch, obvious bad-faith bait

## Rules

- Answer the actual question in public when possible.
- Match reply length to comment length.
- For criticism, concede any true part before explaining the disagreement.
- Never invent proof, metrics, customers, or outcomes.
- If a factual rebuttal is needed, use the fact-check workflow first.
- For leads, be helpful before opening a door to continue privately.
- Ignore spam rather than rewarding it with attention.
- Nothing is auto-posted.

## Output

Return the bucket counts, then copy-ready replies in priority order. Explain
any skipped comments.
