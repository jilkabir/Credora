# Credora repurpose

Extract; do not merely summarize.

## Find

- claims
- evidence and numbers
- stories
- mechanisms
- mistakes
- counterarguments
- useful frameworks
- quotable ideas
- source limitations

## Credibility rule

Keep each extracted claim attached to its evidence status. A source saying
"associated with" must not become "causes". A case study must not become a
universal rule.

## Memory rule

Before proposing angles, compare them with recent content memory when
available. Flag repeated topics, examples, hooks, metaphors, and conclusions.

## Output

Return a source map and 4 to 8 genuinely distinct post angles, each with:
- target reader
- central idea
- evidence status
- novelty score or repetition warning
- recommended format

Draft one at a time unless the user explicitly asks for all.
