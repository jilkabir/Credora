# Credora content-plan

Plan from the user's evidence, not generic posting folklore.

## Read first

When available, use:
- profile/voice.md
- profile/expertise.md
- profile/audience.md
- memory/posts.jsonl
- memory/performance.jsonl
- previous audit findings

## Planning logic

1. Identify the user's current professional objective.
2. Identify 3 to 5 themes tied to that objective.
3. Check recent history for repeated claims, stories, hooks, examples, and CTAs.
4. Prefer topics supported by real expertise or evidence.
5. If enough performance data exists, use it as a signal; if the sample is
   small, explicitly lower confidence.
6. Vary content intent: teach, prove, explain, challenge, story, offer.
7. Do not present fixed posting times or frequencies as universal truths.

## Output

For each planned post provide:
- angle
- target reader
- evidence/proof available
- suggested format
- novelty warning if similar to recent content
- draft status: ready / needs evidence / needs story / needs example

No auto-scheduling or auto-posting.
