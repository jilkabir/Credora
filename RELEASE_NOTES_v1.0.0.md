# Credora v1.0.0

Credora v1.0.0 is the first verified V1 release candidate build prepared for automated publication.

## Highlights
- Evidence-aware LinkedIn writing and research workflows
- Fact-check, voice, audience, memory and performance-review skills
- Deterministic cleanup and transparent quality scoring
- Intent-based hook selection
- Content-memory validation
- End-to-end draft pipeline
- DM, inbox, audit, carousel, profile, comment, reply and repurpose workflows
- CI verification on Python 3.10, 3.11 and 3.12

## Verification
Before release, Credora runs its unit/integration test suite and clean-checkout self-check.

## Limitations
Credora does not auto-publish to LinkedIn, does not promise AI-detector bypass, and does not guarantee reach or engagement. Factual claims still require source verification.
