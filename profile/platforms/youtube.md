# YouTube Rules

## Scripts
Use `profile/talking-style.md`, not the article-writing fingerprint alone. Write for listening: clear spoken sentences, fast pain-point recognition, concrete examples, and transitions that sound natural aloud. Never describe a tool capability that has not been verified when accuracy matters.

## Titles/descriptions
Be specific about the benefit or question without clickbait promises. Do not invent outcomes, urgency, controversy, or numbers.

## Current limitation
Until enough real speaking transcripts exist, talking-style confidence remains limited. Do not pretend the system has learned the user's spoken voice from written articles.

User approval is mandatory before final status.
