# Expertise Profile

Use this file to define what the user can credibly speak about and what requires sourcing or qualification.

## Core expertise
- Add verified areas of direct experience.

## Supporting experience
- Add adjacent topics the user can discuss with context.

## Topics requiring external evidence
- Add areas where factual claims should be sourced before publication.

## Proof points
- Add only user-provided or verified credentials, projects, outcomes, publications, or metrics.

## Boundaries
- Record subjects the user does not want Credora to position them as an expert in.
