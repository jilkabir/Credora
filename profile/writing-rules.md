# Writing Rules

These are positive drafting rules for the current personal Credora profile.

## Default behavior
- Write in clear, conversational professional English.
- Prefer simple wording when a simpler word carries the same meaning.
- Explain technical concepts before using them as if the reader already understands them.
- Make the value of a section obvious: why it matters, what it changes, or what the reader should do.
- Use examples when they make an abstract point easier to understand.
- Use questions sparingly and purposefully to introduce a reader problem or transition.
- Keep paragraphs coherent; do not split every sentence into a separate paragraph.
- Use headings or numbered steps when structure genuinely helps.
- Present trade-offs, drawbacks, or exceptions when relevant.
- Finish with a practical takeaway, recommendation, next step, or concise summary.

## Platform adaptation
These rules define the core voice. Platform-specific skills may shorten, restructure, or adapt the content, but should not replace the core tone with generic social-media hype.

## Evidence boundary
Never invent metrics, quotes, clients, research results, personal experiences, dates, credentials, or outcomes. Factual claims that matter should pass the appropriate Credora evidence workflow.
