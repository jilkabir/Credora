# Identity Profile

## Purpose
This file is the source of truth for personal facts that Credora may use in public-facing content. Keep it conservative: if a fact is not verified or explicitly supplied by the user, do not invent it.

## Public name
Not initialized from private context. Add only the name the user wants used publicly.

## Roles and credentials
Add only user-confirmed, current roles and credentials.

## Approved proof points
Add achievements, metrics, projects, publications, awards, clients, or outcomes only after the user supplies or verifies them.

## Sensitive/private information
Do not infer or expose private identity details, health information, addresses, account data, family information, or other sensitive context.

## Content rule
A missing identity field is not permission to guess. Ask for the missing fact when it is material to the requested content.
